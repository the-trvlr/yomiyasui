# 読みやすい 1.0 — лёгкое чтение японского

Первый публичный релиз **読みやすい (Yomiyasui)** — браузерной читалки для спокойного чтения японских текстов с фуриганой, плавной прокруткой и встроенным японским словарём.

## Что вошло в 1.0

- Импорт EPUB, TXT, Markdown и HTML, а также вставка текста.
- Регулируемая скорость чтения с паузой, продолжением и перезапуском.
- Анализ японского текста в Web Worker и настраиваемая фуригана.
- Словарь JMdict-Simplified с русскими и английскими определениями.
- Поиск по написанию, чтению и переводу; отметка известных слов.
- Книжная полка, навигация по главам, закладки и сохранение позиции чтения.
- Мобильный интерфейс с высокой областью чтения, компактной панелью управления и раскрывающимся словарём.
- Автоматическая начальная подготовка анализатора и словаря с индикацией прогресса.
- Новая иконка и метаданные для установки как веб-приложения.
- CI-проверка и автоматическая публикация на GitHub Pages.

## Начать пользоваться

Откройте https://the-trvlr.github.io/yomiyasui/

При первом запуске дождитесь подготовки анализатора и словаря. Архивы словаря кэшируются в IndexedDB, но поисковый индекс пока строится заново при каждом запуске страницы.

## Важно знать

Приложение статическое: книги, прогресс, закладки и известные слова сохраняются локально в браузере. Облачной синхронизации и аккаунтов нет. Храните оригиналы книг отдельно, если не хотите рисковать локальными копиями.

Подробности, локальный запуск и ограничения: https://github.com/the-trvlr/yomiyasui/blob/main/README.md
