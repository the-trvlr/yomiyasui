# 読みやすい 1.5 — устанавливается и работает без сети

Версия 1.5 делает приложение полноценным PWA: его можно установить на телефон
или компьютер, и после первого запуска оно работает офлайн.

## Что изменилось

### Установка

- `manifest.webmanifest` получил настоящие PNG-иконки: 192×192 и 512×512 для
  установки, отдельная `maskable`-иконка с логотипом в безопасной зоне и
  `apple-touch-icon` 180×180 для iOS.
- В разметку добавлены `apple-mobile-web-app-*` мета-теги: на iOS приложение
  открывается без адресной строки и с правильным названием.
- Иконки генерируются из `site/app-icon.svg` скриптом `scripts/make-icons.mjs`
  (Chrome как растеризатор), поэтому их можно пересобрать, а не рисовать заново.

### Service Worker

- Оболочка (HTML, CSS, JS, конфиг, воркер анализатора, манифест, иконки)
  кэшируется при установке — приложение запускается без сети.
- Анализатор (`vendor/`) и словари (`data/`) кэшируются по мере использования:
  они слишком большие для предварительной загрузки, но после первого чтения
  доступны офлайн.
- Кэш версионируется по `APP_VERSION` и снимку JMdict; при обновлении старые
  кэши удаляются, поэтому файлы разных версий не смешиваются. Совпадение версий
  в `sw.js` и `config.js` проверяется в CI.
- Если места в квоте не хватает, файл просто не кэшируется — чтение продолжает
  работать из сети.

### Офлайн-поведение

- При потере сети статус сообщает, что чтение идёт из кэша; при восстановлении —
  что сеть вернулась.
- Если приложение открывают офлайн впервые (оболочки нет в кэше), показывается
  страница `offline.html` с объяснением и кнопкой «Повторить».

## Проверка

В `npm run smoke:full` добавлен сценарий: страница загружается, service worker
берёт её под контроль, затем сеть отключается и страница перезагружается.
Тест падает, если офлайн-загрузка не удалась.

```
Офлайн: SW контролирует страницу — да, перезагрузка без сети — ок (v1.5)
```

## Ограничения

- Service Worker не уменьшает первую загрузку: анализатор (17,8 МБ) и словарь
  скачиваются один раз, как и раньше. Он гарантирует, что это действительно
  один раз, и даёт офлайн.
- На iOS квота Cache Storage ограничена: тяжёлые словарные файлы могут не
  попасть в кэш. Тогда они работают из сети, чтение — по-прежнему офлайн.
- Приложение всё ещё не уведомляет об обновлении: новая версия подхватывается
  при следующем открытии.
