# 読みやすい 1.1 — вертикальное чтение и надёжная основа

Версия 1.1 добавляет традиционную японскую запись **縦書き** и завершает первый
этап технической перестройки: приложение разобрано на файлы, получило
автоматические проверки и явные лицензии.

## Что нового

### 縦書き — вертикальное чтение

- **Переключение ориентации** в настройках чтения: «Горизонтально» / «縦書き».
  Выбор запоминается в браузере и применяется при следующем запуске.
- Текст идёт **сверху вниз**, столбцы — **справа налево**, как в японской книге.
- **Фуригана справа** от иероглифов: чтение встаёт на своё место автоматически,
  потому что в вертикальном наборе сторона `over` — это правая сторона.
- **Прокрутка справа налево**: строка, которую читаешь сейчас, остаётся у правого
  края, следующие столбцы подтягиваются из левой части области чтения.
- **Пустое поле перед текстом**, как в горизонтальном режиме: линия чтения отстоит
  от левого края на ширину двух столбцов, поэтому в начале видно только первые две
  строки, а остальное место текст занимает по мере прокрутки.
- **Тачпад и колесо**: жест двумя пальцами прокручивает текст по любой оси —
  в вертикальном режиме боковой жест раньше игнорировался.
- Работает в связке с остальными настройками: длина строки задаёт высоту столбца,
  межстрочный интервал — расстояние между столбцами, фуригана и отметки
  известных слов сохраняются.
- На мобильных устройствах вертикальный режим использует ту же область чтения.

### Техническая основа

- `index.html` разобран на разметку, `app.css` и `app.js` (ES-модуль).
- `site/config.js` — единственный источник версии приложения и снимка JMdict;
  CI падает, если версия захардкожена или расходится с разметкой.
- Проверки структуры вынесены в модуль и покрыты тестами (`node:test`).
- Добавлены ESLint, Prettier и `.editorconfig`.
- Локальный стенд: `npm run dev` отдаёт новую версию и копию `main` рядом,
  `npm run smoke` сравнивает их в headless Chrome по отпечатку DOM.
- Добавлены `LICENSE` (MIT на код) и `NOTICE.md`: данные JMdict распространяются
  по CC BY-SA 4.0, библиотеки — по Apache-2.0 и MIT.

## Исправления

- **EPUB с фуриганой больше не дублирует текст.** Раньше при импорте книги
  `textContent` захватывал содержимое `<rt>` и `<rp>`, и «漢かん» попадало в текст.
  Теперь разметка ruby вырезается до извлечения текста.
- После успешного ручного подключения словаря больше не остаётся висеть
  предупреждение «не удалось подключить словарь».
- Область чтения помечена `lang="ja"` — корректное произношение в TTS
  и экранных читалках.
- Удалён неиспользуемый код (стартовый глоссарий, несколько мёртвых функций).
- Прокрутка колесом и тачпадом больше не зависит от того, по какой оси пришёл жест: раньше в вертикальном режиме боковой жест двумя пальцами не прокручивал текст.

## Важно знать

- При переключении ориентации позиция сохраняется **по доле прочитанного**.
  Текст переверстывается, поэтому конкретная строка может сместиться на
  несколько столбцов. Точная привязка к абзацу и символу запланирована
  в следующем обновлении.
- Вертикальный режим — новый. Он проверен в Chrome и Safari, но необычная вёрстка
  книг (таблицы, изображения, сложные сноски) может выглядеть иначе, чем
  в горизонтальном.
- Словарный индекс по-прежнему строится при каждом открытии страницы — это
  следующая крупная задача (см. [ROADMAP.md](ROADMAP.md), фаза 2).

## Обновление

Специальных действий не требуется. Книги, позиции чтения, закладки и известные
слова остаются в локальном хранилище браузера: формат данных не менялся.
Выбранная ориентация текста хранится в `localStorage` под ключом
`kotoba-orientation`.

npm run verify      # структура, линт, формат, тесты
