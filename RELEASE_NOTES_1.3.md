# 読みやすい 1.3 — первый запуск без ожидания

Версия 1.3 убирает главную задержку первого запуска: анализатор и словарь
больше не загружаются друг за другом.

## Что изменилось

### Параллельная загрузка

Раньше словарь стартовал только после того, как полностью скачается и
инициализируется анализатор Kuromoji (17,8 МБ), а затем ещё и разберётся
демонстрационный текст. Теперь оба ресурса качаются одновременно: первый запуск
упирается в самый медленный файл, а не в их сумму.

### Статус в шапке

Пока идёт подготовка анализатора или разбор книги, прогресс словаря остаётся
в панели словаря и на экране первого запуска — он больше не перебивает статус
анализатора в шапке.

## Замеры

Один браузер, CPU замедлен в 4 раза, сеть ограничена профилем 4G
(1,5 МБ/с, задержка 70 мс), локальная раздача без сжатия:

| Метрика | 1.2 (последовательно) | 1.3 (параллельно) |
|---|---|---|
| Словарь готов к поиску | 22 191 мс | **4 355 мс** |
| Полная загрузка словаря | 70 760 мс | 37 037 мс |
| Полная готовность страницы | 79 471 мс | 44 811 мс |

На быстром соединении разница меньше, но порядок тот же: поиск перестаёт ждать
анализатор.

Повторить:

```sh
npm run dev
node scripts/measure.mjs --url http://127.0.0.1:8000/site/ --network 4g
```

У `scripts/measure.mjs` появился профиль сети (`--network 4g` или `3g`), чтобы
сравнивать версии в одинаковых условиях.

## Что дальше

- Предрассчитанный индекс форм и глоссов — сейчас `formIndex`/`prefixIndex`
  строятся в браузере после загрузки.
- Шардирование полного словаря вместо загрузки 34 МБ целиком.
- Анализатор Kuromoji (17,8 МБ) остаётся самым тяжёлым ресурсом; следующий шаг —
  облегчённый режим сегментации для быстрого старта.
