# 読みやすい 1.2 — словарь собирается заранее

Версия 1.2 убирает самую долгую операцию запуска: словарь больше не скачивается
архивами и не собирается в браузере. Его готовит CI, а приложение загружает
готовый файл — сначала «ядро» частых слов, затем полный набор.

## Что изменилось

### Словарь собирается на CI

- Новый скрипт `scripts/build-dictionary.mjs` читает оба архива JMdict,
  сливает английские и русские записи по id и пишет компактный JSON:
  кортежи вместо объектов, части речи вынесены в общую таблицу, теги
  отброшены (приложение их не читает).
- Из запуска приложения ушли распаковка JSZip и разбор ~60 МБ исходного JSON:
  браузер получает один уже собранный файл.
- Сборка встроена в `scripts/prepare-site-assets.sh`, поэтому GitHub Actions
  готовит словарь при каждом деплое. Архивы остаются в сборке как ручной
  резервный путь: если собранного файла нет, приложение грузит их по-старому.

### Сначала «ядро» частых слов

- 22 645 частых слов вынесены в отдельный файл (1,7 МБ gzip против 10,4 МБ
  у полного). Поиск и карточки слов работают сразу после него, полный словарь
  догружается в фоне.

## Замеры

Один и тот же браузер, CPU замедлен в 4 раза, локальная раздача:

| Метрика | 1.1.1 | 1.2 |
|---|---|---|
| Словарь готов к поиску | 23 408 мс | **2 165 мс** |
| Полная загрузка | 23 408 мс | 12 077 мс |
| JS heap после загрузки | 412 МБ | 304 МБ |
| Запрос「静か」 | 4 результата, первым「静か」 | так же |
| Запрос「ночь」 | 35 результатов, первым「暮夜」 | так же |

Повторить: `npm run dev`, затем
`node scripts/measure.mjs --url http://127.0.0.1:8000/site/`.

## Что ещё не сделано

- Поисковый индекс (`formIndex`/`prefixIndex`) по-прежнему строится в браузере
  после загрузки. Это следующая часть фазы 2: предрассчитанный индекс форм и
  глоссов на диске.
- Полный словарь всё ещё загружается целиком, а не шардами по требованию.
- Память снизилась, но остаётся высокой: 218 898 записей живут в куче.

## Проверка

```sh
npm run verify
npm run baseline && npm run smoke:full
```

`smoke:full` теперь дополнительно проверяет, что словарь загрузился и что
поиск по「静か」возвращает «静か» первым результатом.
